# 三国战斗原型（P0/P1）

## 打开与运行

使用 Godot 4.7.2 导入 `prototype/project.godot`，打开后按 F6 运行 Main.tscn，或按 F5 运行工程。不需要新建工程或安装插件。

## 手工验收

1. 点击熊（A军团），悬停空格检查路径，点击移动；Esc取消选择。猫是B军团，同样可移动。
2. 点击左上角“A → B：进入测试交战”。移动期间入口不执行。
3. 修改某支部队兵力或武将伤势，确认其他成员及另一军团不受影响。
4. 交战面板打开时按方向键、确认键并点击面板，地图不得同时移动。
5. 返回地图，检查单位位置；再次进入，检查修改仍存在。
6. 关闭重开会恢复测试初值，本轮不提供磁盘存档。
