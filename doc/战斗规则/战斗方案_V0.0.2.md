# 三国开放世界战棋游戏：战斗方案 V0.0.2

- 版本：V0.0.2
- 日期：2026年11月6日
- 定位：本轮讨论形成的战斗规则基线，供后续玩法细化、框架筛选和原型验证使用。
- 状态说明：正文明确区分已确定规则、设计建议与待定事项。未确定的公式、机制和数值不视为正式规则；进攻方速度加值＋200为已确认的暂定平衡参数。
- 版本优先级：以本版本的十二格阵形、八支部队、每名武将最多指挥四支部队为准，替代早期六个部队位置、每人最多三个位置等设想。

## 版本变更摘要

V0.0.2在原有三将八部队、十二格阵形与持续战损规则上，新增并确认：

- 双方内部成员共同按最终速度排序，同速随机先手。
- 进攻方内部成员本次排序暂加200速度。
- 射程包含最小和最大值，最终修正后向下取整数。
- 前后间距100、左右间距30，采用相加距离；基础保护按列判定。
- 普通攻击与反击共用每次交战一次的基础行动，伤害先结算，再按受击后的状态反击。
- 反击检查射程与阻挡，不能形成普通反击连锁。
- 支持战前攻击优先级与逐个手动指定目标。
- 无合法目标可以待机；每次攻击及反击完整结算后，符合条件的待机成员按速度优先重返行动。
- 所有剩余成员均无法执行有效行动时结束交战，防止无限待机。

## 一、游戏定位与开发背景

游戏以三国历史为背景，采用2D像素表现。玩家在探索地图上自由移动、招募角色、组织队伍；进入战斗后切换至战棋模式，战后返回探索流程。体验方向为开放探索RPG、回合制战棋和队伍经营的结合。

玩家可以让武将独行，也可以组织带兵军团。个人能力与统军能力分别发挥作用，个人战和军团战允许发生在同一战场。

开发者没有游戏开发经验，编程与美术基础很少，主要依靠AI协助开发。应优先考察可复用的框架、插件与素材，以小规模原型验证后再扩大内容。

技术方向暂以Godot 4稳定版、GDScript、Windows单机为优先考察方案，尚未完成最终框架选型；如其他引擎有明显更适合且经过验证的基底，可以重新评估。引擎与语言是当前技术建议，不是战斗规则的硬性限制。

## 二、设计目标

1. 让武将个人冒险与带兵作战共享一致的操作逻辑。
2. 通过军团内部编组、前中后排、兵种与武将配置形成战术取舍。
3. 人数通常具有压倒性；强力武将在面对成建制部队时，主要依靠短暂支撑、周旋与撤退，而非稳定正面取胜。
4. 个人属性在个人作战中影响较大，在军团作战中的直接提升相对有限；武将仍通过统率、谋略、技能和能力加成重要地影响军团。
5. 战损持续影响后续作战与探索，兵力管理具有实际代价。

## 三、术语与两个战斗层级

| 术语 | 本方案定义 |
| --- | --- |
| 武将 | 可独立拥有属性、装备、技能、伤势与状态的角色；包括谋士型角色 |
| 部队 | 占据一个内部阵形位置、具有兵种和实际兵力的士兵集合；不等于单个士兵 |
| 军团／编组 | 外部战场上的一个行动整体，最多包含三名武将和八支部队；无兵时仍保留编组 |
| 外部战场 | 用于移动、接敌和选择目标的方格地图 |
| 内部阵形 | 军团内部前中后排共十二格的位置布局，不等于外部战场的十二个格子 |
| 一次交战 | 外部发起攻击后，内部成员依次执行有限交战，再返回外部战场 |

### 3.1 外部战场：已确定

- 战斗优先进入独立地图。探索地图原地展开暂不作为当前要求。
- 使用方格地图。
- 单个武将或整个军团在外部均占一格。
- 各战场单位依次行动，不采用我方全体行动完再统一轮到敌方的阵营回合设计。
- 混合战场允许独行武将与带兵军团同时存在并交战。
- 外部军团按当前可作战内部成员的平均速度降序行动：速度总和÷成员数量。每名武将、每支部队各计一个成员，不按士兵人数加权；失能武将、零兵力或其他不可作战部队不参与计算。独行武将沿用同一规则。
- 每轮开始重新计算平均速度并固定本轮队列；同值按固定单位ID排序，不强制敌我交替。本轮中途失去作战能力的外部单位跳过，其他战损引起的平均速度变化下一轮生效，本轮不重排。
- 进攻方＋200只用于进入内部交战后的成员排序，不计入外部平均速度。
- 移动与攻击的行动额度、外部接敌距离和撤退规则待定。内部射程与反击规则见下文，不直接等同于外部军团的对应属性。

### 3.2 内部交战与行动额度：已确定

- 武将与部队保留各自身份和状态，在交战中依次行动；有士兵时，武将也会出手。
- 一次交战是有限过程，不自动持续至一方被消灭。
- 每名可行动成员每次内部交战具有一次基础行动，普通主动攻击与普通反击共用这一额度。
- 每次内部交战开始时恢复基础行动，不按外部回合跨交战累计消耗。
- 同一军团在外部一回合内与多个敌军分别交战时，每次恢复内部基础行动，但兵力损失、伤势及其他持续状态仍然保留。行动恢复不等于治疗或状态清除。
- 技能可以提供额外行动或反击机会；具体技能规则尚待制定。

### 3.3 速度与行动排序：已确定

- 每名武将、每支部队分别计算自身最终速度。
- 兵种或武将提供基础速度，武将能力、技能等可以修正速度；详细加成公式待定。
- 双方成员放入同一个行动序列，由快到慢行动，不先固定执行完某一方的全部成员。
- 主动发起本次交战的军团，其所有内部武将与部队获得暂定＋200的排序速度加值，仅用于本次内部交战排序，不直接改变外部军团行动顺序。
- 本次排序速度＝成员经其他效果修正后的速度＋进攻先手加值；防守方无此进攻加值。
- 速度相同，随机决定先后。＋200是可在平衡阶段调整的参数，不保证进攻方无条件先于所有防守成员行动。
- 反击按受击回应规则插入，不需要等待受击者在速度队列中的正常轮次；待机重返规则见3.7。

速度是内部成员的排序依据；外部军团另按3.1规定的可作战成员平均速度排序。速度效果在交战中变化时是否重排，以及随机结果的保留方式，尚待确定。

### 3.4 射程与距离：已确定

每种兵种、每名武将及其技能可具有不同攻击距离。攻击距离是包含最小值与最大值的区间，武将和技能可以修正，最终计算完成后向下取整数。

例如：计算结果为277.8，最终显示277，不按100档位截成200；最大射程499不能命中距离500的目标。

目标必须满足：**最终最小射程 ≤ 目标距离 ≤ 最终最大射程**。因此射程200—277不能攻击距离100或300的目标，可以攻击距离200或260的目标；这些仅代表距离合法，仍须检查阻挡与技能限制。

双方内部阵形均为三排四列。令前、中、后排的排号分别为0、1、2，列号为0、1、2、3，双方列号以实际正面对位为准：

**目标距离＝100＋100×（攻击者排号＋目标排号）＋30×双方列号差的绝对值。**

距离采用前后与横向直接相加，不使用直线几何距离，也不因界面镜像改变对位关系。

| 攻击者所在排 | 敌方前排（同列） | 敌方中排（同列） | 敌方后排（同列） |
| --- | ---: | ---: | ---: |
| 我方前排 | 100 | 200 | 300 |
| 我方中排 | 200 | 300 | 400 |
| 我方后排 | 300 | 400 | 500 |

| 示例 | 前后距离 | 横向距离 | 最终距离 |
| --- | ---: | ---: | ---: |
| 前排攻击前排，相差一列 | 100 | 30 | 130 |
| 前排攻击中排，相差两列 | 200 | 60 | 260 |
| 后排攻击后排，相差三列 | 500 | 90 | 590 |

本规则用于内部攻击距离；外部格子间的接敌距离另行设计。不同攻击和技能的射程修正规则、越界或异常区间处理待定。

### 3.5 按列保护与目标选择：已确定

- 基础保护按目标所在列判定：目标前方存在符合阻挡条件的成员时，普通攻击不能直接越过该阻挡攻击后方。
- 同列前方阻挡被突破后，可按射程与其他条件攻击暴露的后方目标。
- 射程只负责是否够远及是否进入近距离盲区；掩护、阻挡和技能另行判断是否允许攻击该目标。
- 技能可以改变越过前排、阻挡或掩护的能力；不默认所有远程攻击都无视保护。
- 玩家可以战前设置攻击优先级，也可以在交战中逐个手动指定合法目标。
- 具体优先级选项、自动与手动切换方式、各兵种是否构成阻挡以及掩护范围扩展，尚待确定。

### 3.6 攻击与反击：已确定

1. 攻击者选择合法目标并执行攻击，消耗其基础行动。
2. 先完整结算本次攻击造成的兵力损失、武将伤势、失能及相关状态影响。
3. 受击者仍可作战、尚有基础行动且满足对攻击者的射程、阻挡和其他反击条件时，执行普通反击并消耗基础行动。
4. 反击能力按照受击后的剩余兵力、伤势与状态计算，不使用受击前的完整战力。
5. 普通反击不再触发对方普通反击，避免无限连锁。
6. 基础行动已通过主动攻击或反击用掉的成员，再次受击不能普通反击，技能额外提供的机会除外。
7. 已反击的成员之后轮到正常队列位置时，不再获得普通主动攻击。

例如：甲先攻击乙，乙从100名可战斗士兵降至70名，乙以70名士兵对应的受击后能力反击；甲乙均已消耗基础行动。若乙无法反击，不凭空视为已经执行一次反击，后续是否行动由其基础行动和合法条件决定。

特殊反击、范围攻击受击者的反击组织方式、技能消耗与额外行动上限尚待确定。

### 3.7 待机与重新行动：已确定

- 轮到成员时，如果没有合法攻击目标，可以待机，保留基础行动，不立即取消其本次行动机会。
- 每次“攻击＋其反击”完整结算后，重新检查待机成员；如果没有触发反击，则在该次攻击完整结算后检查。
- 出现合法目标的待机成员，按本次交战速度从高到低优先行动，优先于原队列的下一名成员；同速随机。
- 待机重返的行动同样执行完整攻击与反击结算，随后再次检查其他待机成员。
- 待机期间受击，仍可在满足条件时反击；如果通过反击消耗基础行动，则从后续普通主动行动中排除。
- 高速成员可以等待友军击破阻挡，再攻击新暴露目标；不会在友军攻击与其反击尚未结算完时插入。
- 所有剩余成员都无法执行有效行动时，本次交战结束，不无限循环待机。

例如：高速弓兵因阻挡没有合法目标而待机；步兵随后击破阻挡，完成该次攻击及可能的反击；重新检查发现弓兵已拥有合法目标，弓兵优先于原队列下一成员行动。

是否允许有合法目标时主动待机、是否允许放弃行动，尚未单独确认，不作为本版既定规则。

### 3.8 交战结束

本次基础行动及已触发的额外行动处理完成，或所有剩余成员均无法执行有效行动时，结束内部交战并返回外部战场。一方已无可继续作战成员时可提前结束；整个外部战斗的胜负、逃脱与撤退条件另行制定。

## 四、军团编制与阵形

### 4.1 编制上限：已确定

| 项目 | 上限与规则 |
| --- | --- |
| 武将 | 最多三名，一名主将、最多两名副将 |
| 部队 | 最多八支，占据最多八个内部位置 |
| 内部阵形 | 前、中、后排各四格，共十二格 |
| 位置使用 | 武将与部队共用十二格；每名武将或每支部队各占一格 |
| 重复兵种 | 允许在多个位置放置相同兵种的部队 |
| 填满要求 | 不要求填满；满编三将八部队共占十一格，至少留一格空位 |

前、中、后排与左右列共同决定内部攻击距离，基础保护按列处理，具体见3.4—3.5。攻击穿透、绕后、保护范围扩展、内部位置调整及空位的其他战术效果后续细化。

### 4.2 指挥归属：已确定

- 每名武将最多负责四个部队位置。
- 同一支部队只能归属一名武将，不能重复选择或叠加多名武将的普通统率归属。
- 指挥归属不限制内部距离；前排武将可以负责后排部队。
- 军团内部必须保留部队与武将的归属关系。
- 普通统率加成作用于自己负责的部队；军团技能可以按明确条件影响其他部队。
- 不负责部队的武将仍可担任谋士，提供军团谋略、主动和被动技能。

例如：主将负责四支部队，一名副将负责另外四支，另一名副将不带兵、专门提供谋略。此为合法编组示例，不限定玩家必须如此安排。

是否允许暂时无人负责的部队，以及阵形调整后归属如何继承，尚待确定。

## 五、个人能力与军团战力

### 5.1 已确定原则

- 个人战斗侧重武将自身属性、装备和技能。
- 军团战力以兵种、兵力、战术等为基础，结合武将能力、统率、谋略和技能。
- 不采用“把武将某项属性直接乘一个系数”就完成全部军团战力计算的简单处理。
- 个人战与军团战统一战场操作，但不强制使用同一套伤害或生命计算公式。
- 高武力不能无条件抵消显著兵力差距。

### 5.2 后续计算设计方向：建议，尚未定案

将计算拆成可解释的部分：部队基础能力、有效兵力、指挥效果、阵形与战术、技能和状态修正。通过这些关系形成深度，暂不为复杂而引入庞大公式。

速度、最小与最大射程已确认为内部成员属性，但具体基础值、加成公式和效果叠加顺序待定。尚未确定完整属性列表、人数收益曲线、兵种克制、地形限制、士气系统、武将个人攻击对部队的换算，以及外部军团行动属性的计算方式。

## 六、武将受伤、失能与指挥影响

### 6.1 已确定

- 即使军团仍有士兵，武将也可能被特定攻击、突袭或技能伤害。
- 武将受伤与士兵损失分别记录，不能只用一个共享军团生命值代替全部成员状态。
- 武将失能时，其负责的部队受到负面影响。
- 失能武将停止提供需要本人维持的效果；不是所有既有效果都必然立即消失，具体按效果定义。
- 主将失能，除上述影响外，额外产生军团级指挥惩罚。

### 6.2 待定

- 失能的判定条件，以及受伤、昏迷、死亡等状态是否分别存在。
- 指挥惩罚的内容、程度与持续时间。
- 副将是否能够自动或手动接任主将。
- 失能武将的部队是否可以战中转交，以及全部武将失能后的处理。
- 武将死亡、被俘、逃脱与战败保护规则。

## 七、无兵编组与个人作战

### 7.1 已确定

- 战斗中不允许武将主动脱离编组，战后可以调整。
- 士兵全部耗尽时，原编组不自动拆散。
- 剩余武将保留内部站位，在外部仍占一格，按内部规则依次交战。
- 一名无兵武将可以作为单人编组；最多三名无兵武将可以共同组成一个编组。
- 人数优势通常具有压倒性。个人面对成建制部队，以短暂支撑、周旋和逃脱为主要生存方式，正面交战通常必败。

### 7.2 待定

士兵由有兵变为无兵时，移动能力、可用技能、内部速度变化与外部显示如何处理仍待定。无兵转换本身不另行默认刷新行动；既定的每次内部交战恢复基础行动规则仍适用。

## 八、兵力、伤兵、阵亡与后勤

### 8.1 已确定

- 士兵人数是真实且持续的资源，影响军团能力、消耗、行军与后续战斗。
- 兵力损失区分伤兵与阵亡。
- 伤兵可以恢复；阵亡必须通过补充兵员弥补。
- 可以用类似生命条的方式显示兵力，但不能把所有兵力损失都当作可直接恢复的普通生命值。
- 每支部队需要分别保留兵种和兵力状态，以支持内部交战与战损追踪。

### 8.2 待定

- 每支部队的兵力上限，以及上限是否受武将、兵种或成长影响。
- 伤亡划分、治疗速度、恢复条件、补兵来源与成本。
- 伤兵的补给消耗、运输负担和行军影响。
- 零可战斗兵力但仍有伤兵的部队，如何保留、显示和占位。
- 补兵后训练、经验、装备等如何继承。

## 九、一次战斗的概念流程

以下为已确定规则的流程整理，具体触发、胜负条件与界面尚待设计：

1. 探索中触发战斗，进入独立方格战场。
2. 将个人武将或军团作为外部单位部署。
3. 外部单位按待定排序规则依次行动，执行移动、攻击或其他可用指令。
4. 发起交战后恢复内部基础行动，计算双方速度，加入进攻方暂定＋200加值，共同排序，同速随机。
5. 按射程、距离与按列保护筛选目标，使用战前攻击优先级或逐个手动指定执行攻击。
6. 先结算攻击伤害，再检查受击者是否能反击；攻击与反击共用基础行动，反击使用受击后的能力。
7. 每次攻击与反击完整结算后，检查待机成员并按速度优先处理，直至本次有限交战结束。
8. 在结算过程中及时更新成员伤势、兵力、伤亡与技能状态，处理武将失能带来的指挥影响。
9. 如果士兵耗尽，保留武将编组继续作战。
10. 返回外部战场，继续后续行动，直至满足胜负或退出条件。
11. 战后保留战损，进入恢复、补兵和编组调整流程，返回探索。

## 十、框架筛选与首个原型

本节为开发建议，不代表已经选定框架或完成技术验证。

### 10.1 优先复用

方格地图、寻路、选中与移动、攻击范围、行动排序、基础界面，以及经过适配的对话等外围系统。

### 10.2 重点检查的扩展能力

- 一个外部单位能否容纳多名武将与多支部队。
- 能否将默认单角色扣血结算替换为内部有限交战。
- 能否保存十二格阵形、部队归属和成员独立状态。
- 能否支持成员最小与最大射程、前后与横向相加距离及按列保护。
- 能否支持双方共同速度排序、同速随机、进攻速度加值，以及消耗基础行动的即时反击。
- 能否在完整攻击与反击结算后，让待机成员按条件优先重返行动，并正确终止无效等待。
- 能否在成员失能后更新部队加成与军团状态。
- 能否保留伤兵、阵亡和无兵编组，连接探索与存档。

现成项目即使拥有回合制战斗，也不等于已经支持本方案。以实际试改验证复用价值，不以展示效果或功能数量直接判断。

### 10.3 最小验证场景

使用占位美术，让两支小规模军团在外部方格接敌，进入内部阵形结算；至少验证不同部队归属、谋士技能、武将受伤失能、伤兵与阵亡、士兵耗尽后武将编组继续行动，以及战后状态保留。

V0.0.2还需验证：射程277不能攻击距离300，射程499不能攻击距离500；相差列数影响距离；射程足够但被同列阻挡时无法直接攻击后方；反击使用受击后的兵力且消耗基础行动；再次交战恢复行动但不恢复战损；高速成员待机后在阻挡突破时优先重返；双方均无合法行动时能够结束。

首先验证数据与结算，再增加复杂动画和正式三国美术。原型不要求满编全部内容，但结构应能表达三将八部队的上限。

## 十一、后续讨论顺序与待定边界

本版本已经确认内部速度、射程、基础反击与待机机制；后续不再将这些整体视为未定。

1. 确定内部交战剩余边界：速度变化是否重排、技能与范围攻击如何反击、能否主动待机及放弃行动、基础加成与效果叠加顺序。
2. 明确哪些成员能阻挡、穿透与绕后技能、掩护范围，以及战中是否可以调整内部位置。
3. 明确外部行动排序、行动额度、接敌距离、移动与撤退，保持与内部成员行动分离。
4. 明确部队兵力上限、伤亡恢复、无人指挥部队及武将失能后续处理。
5. 筛选并实际试改候选基底，再细化属性、技能与伤害公式。

以上为建议顺序；未确认机制不自动补成正式规则。进攻速度加值200、各类基础属性和技能数值需在原型阶段平衡。

## P2讨论补充：R2行动力与神力（已确认）

### 两类行动力
- 移动行动力：默认持有上限1点，可提高至最高4点；每轮固定恢复1点，不超过当前上限；每次移动消耗1点。
- 战斗行动力：每轮默认恢复2点，恢复量可通过其他手段提高至最高10点；默认持有上限2点，可提高至最高20点；恢复不超过当前上限。
- 待命不消耗点数，结束当前军团本轮行动；两类剩余点数继承至下一轮，不在本轮队列末尾再次行动。
- 战斗行动消耗：神眷3点；军团战技、攻击、战法、策略、道具各2点；防御1点。
- 防御指令结束当前军团本轮行动，保留两类剩余点数，防御力增加50%，持续至整个战场下一回合开始统一解除，而非该军团下次开始行动。
- 主动攻击以及具有进攻性质的神眷、军团战技、战法、策略，执行后禁止本轮后续移动；技能或buff可以解除限制。治疗、辅助、使用道具不自动锁定移动；被敌方攻击和内部反击不触发此限制。
- 不采用移动一次、攻击一次及攻击后自动结束行动的旧建议；行动次数由可用点数约束。

### 武将神力
- 神力属于武将本人；本人及所辖每支部队的事件分别计算，收益归属该武将，不按士兵人数计数。
- 首次初始化为0点，初始持有上限100点，可提升至最高400点。
- 神力跨内部交战、整场战斗、探索与下一场战斗持续保留，不自动清零或补满。
- 暂定收益：主动攻击＋1，主动攻击暴击额外＋1；反击＋0.5，反击暴击额外＋0.5；闪避＋1，内部防御反应＋1。不同事件可叠加，保留半点精度。
- 攻击被闪避仍获得攻击收益：主动攻击＋1或反击＋0.5；成功闪避方另获得＋1。
- 内部防御反应由武将或部队能力、概率触发，是受击反应；其具体效果后续制定。外部防御指令及其防御力buff本身不触发该神力奖励。
- 神眷基础消耗100点神力，部分技能升级后消耗可超过100点；须满足具体技能配置的神力消耗，并支付3点战斗行动力。
- 收益、上限、消耗与加成等平衡数值集中配置，避免分散硬编码；当前收益为暂定参数，后续通过战斗记录调整。

已确认的初始化与恢复：每场外部战斗开始时，移动行动力1点、战斗行动力2点；后续能力可按配置改变开战初值。第一回合使用开战初值，不额外恢复。从第二回合起，在整个战场每轮开始时统一恢复：移动固定＋1，战斗默认＋2（可按已确认规则提高），不超过当前持有上限。两类行动力只在本场战斗内通过待命继承，不跨战斗保留；神力跨战斗保留。

尚待明确：具体技能效果及P2实现范围。未定事项不由代码默认值代替确认。


### R3外部攻击距离（已确认）
- 外部攻击范围根据军团内部当前可作战成员（包括武将、部队）的最大攻击距离初步筛选，不固定为四向相邻。
- 横向或纵向相邻的外部距离增量为0；斜向相邻增量100；横向或纵向中间隔一个格子增量200。
- 内部每次攻击的实际距离＝原内部阵形距离＋本次外部距离增量。各成员仍分别判断自身射程及其他合法条件。只有至少一名当前可作战成员能按叠加后的距离、最小／最大射程及阵形阻挡规则攻击到一名合法敌方目标，才允许发起普通交战；最大射程仅用于初步筛选。
- 例如双方同列前排原距离100，外部斜向相邻增加100，实际距离200。
- 通用公式已确认：设横纵格位差的绝对值为dx、dy（双方处于不同格），外部距离增量＝200×(max(dx,dy)－1)＋100×min(dx,dy)。横纵互换结果相同；按双方位置计算，不使用移动绕行路径长度。
- 示例：位移(2,1)增量300，(2,2)增量400，(3,1)增量500；双方同列前排实际距离分别为400、500、600。


### R4整场胜负（已确认）
- 敌方所有外部军团均无可作战成员、我方仍有可作战成员时，我方胜利；反之失败。双方均无可作战成员时平局。
- 士兵耗尽但仍有可作战武将的军团不算被击败。一次内部交战结束而双方仍有可作战军团时，返回外部战场继续。
- 一次攻击及其反击完整结算后检查胜负，不在结算中途提前结束。
- P2不加入占领据点、坚持指定回合等特殊胜利条件。


### R5失去作战能力的军团占位（已确认）
- 军团全员失去作战能力后，移除外部格子占位，其他军团可以进入或经过该格。
- 该军团不再参与行动，也不能成为普通攻击目标。
- 保留军团编组、成员状态、战损及日志，不删除数据；内部零兵力或失能成员的阵形记录仍保留。
- 仍有可作战武将或部队的军团继续占位并参与战斗。
- 俘虏、救援及战场复苏机制尚未确定，不纳入本条。


### R6移动距离与地形（已确认）
- 移动行动力决定移动次数，移动范围决定单次距离；每次确认执行移动消耗1点移动行动力，不按经过格数扣行动力。
- 仅上下左右四向移动，不走斜角；军团单次移动范围取内部当前可作战成员（武将及部队）移动范围的最低值；失能武将及零兵力等不可作战部队不参与计算，独行武将使用自身移动范围。
- 按实际可达路径计算距离，绕行计入步数；可通行地形每格消耗1点移动距离，不可通行格不能进入。
- 友军占位格可以穿过，但不能作为移动终点；敌军占位格不能进入，也不能穿过。
- 预览和取消移动不扣行动力；确认执行时消耗。少于最大移动距离的移动同样消耗1点移动行动力。
