# P2 外部战斗循环开发方案 V0.0.1

- 日期：2026年11月6日
- 状态：开发方案已建立；外部行动规则R1—R7已确认，基础规则及实施范围已确认，尚未开始P2实现。
- 前置基础：P0操作验收通过；P1首版用户验收通过，数据约束及边界自动检查完成。
- 规则来源：《战斗方案 V0.0.2》及P1用户确认补充；本文中的建议不自动成为规则。

## 一、目标与场景边界

在独立外部方格战场上，让双方多支军团按单位依次行动，完成移动、接敌、内部有限交战、返回战场、继续行动及整场结束的小循环。

探索场景为传统RPG场景，可进一步进入城镇、迷宫，属于P4工作。外部战场不是探索大地图；内部交战是两个外部单位接敌后的过程。内部演出加速/关闭为表现层需求，P2先使用逐次目标选择与日志，不引入动画制作。

## 二、已确定的基础

- 外部单位各占一格，独行武将与带兵军团共享操作方式。
- 外部按单位逐个行动，不采用一方全部行动完再轮到另一方。
- 外部行动额度与内部成员基础行动独立管理。
- 每次内部交战恢复可行动成员的基础行动，不恢复兵力或伤势。
- 内部使用P1已确认的排序、射程、阻挡、反击及待机规则。
- 兵力归零不拆散编组；失能成员保留数据，不能只用共享军团生命值表达战损。

R1—R7已逐项由用户确认，完整规则见本文末尾确认记录；技能和神力实施范围见末尾确认记录。原一次移动、一次攻击及四向相邻接敌建议均已被替代。

P2不加入外部撤退、解除攻击后移动限制的特殊能力、地形伤害及隐藏单位。规则调整须同步验收用例。

## 四、实现结构

1. 战场会话持有单位ID、阵营、位置、军团引用、本轮固定队列、两类行动力及上限/恢复量、移动锁定、防御状态和回合序号。军团数据仍由会话拥有，画面只引用，不在返回时重新生成。
2. 独立外部行动控制器管理当前单位、移动完成、发起交战和结束行动。GameBoard继续提供选择、路径与移动，不承担内部结算。
3. Encounter接收进攻/防守军团引用、本次外部距离增量和种子。P2需要将P1测试界面改为可接收任意双方的可复用界面，移除对固定A/B及P0节点的依赖；保留P1测试入口。
4. 内部结算完成只回传结果并释放输入锁；战场控制器确保本次攻击仅消费2点战斗行动力一次，并更新移动锁定、占位和胜负。重复点击及重复完成回调不得重复扣额度或重复发起交战。
5. 使用明确状态：等待指令、移动中、交战中、战场结束。交战/移动期间禁止其他单位操作，恢复时只开放当前状态允许的指令。
6. 种子、外部行动、内部事件和结果写入可观察日志。沿用临时伤害，不加入正式指挥惩罚与伤兵阵亡换算。

## 五、最小验证场景与实施顺序

场景使用小型方格战场、占位美术，双方各两支外部单位；至少一支为独行武将，其余为带兵军团。每支军团成员ID全局唯一，测试属性明确标注。

1. 确认R1—R7，建立固定测试配置和预期顺序。
2. 完成军团会话与外部行动控制器、当前单位和额度显示。
3. 接入当前单位选择、路径预览、移动确认/取消；修正必要的实际路径步数限制。
4. 接入按最大射程初筛及真实合法目标校验的敌军选择、外部距离增量及可复用内部交战界面。
5. 完成交战返回、额度消费、单位失能更新、回合推进及胜负。
6. 补齐重复输入与状态往返检查，人工完整打一场战斗并保存基线。

## 七、交付与阶段边界

交付：可运行测试战场、外部控制器、内部界面接入、自动检查、人工验收步骤及结果记录、Git基线。

不纳入本阶段：探索/城镇/迷宫、正式美术、AI自动选敌、技能、正式伤亡与指挥公式、磁盘存档、演出速度控制。Windows独立exe模板安装及导出验收为并行技术待办，不作为已经通过的验证。

P2通过后进入P3持续状态：正式伤亡分类、武将失能影响、无兵编组细节与存取；未定玩法需先对齐。


## P2讨论补充：R2行动力与神力（已确认）

### 两类行动力
- 移动行动力：默认持有上限1点，可提高至最高4点；每轮固定恢复1点，不超过当前上限；每次移动消耗1点。
- 战斗行动力：每轮默认恢复2点，恢复量可通过其他手段提高至最高10点；默认持有上限2点，可提高至最高20点；恢复不超过当前上限。
- 待命不消耗点数，结束当前军团本轮行动；两类剩余点数继承至下一轮，不在本轮队列末尾再次行动。
- 战斗行动消耗：神眷3点；军团战技、攻击、战法、策略、道具各2点；防御1点。
- 防御指令结束当前军团本轮行动，保留两类剩余点数，防御力增加50%，持续至整个战场下一回合开始统一解除，而非该军团下次开始行动。
- 主动攻击以及具有进攻性质的神眷、军团战技、战法、策略，执行后禁止本轮后续移动；技能或buff可以解除限制。治疗、辅助、使用道具不自动锁定移动；被敌方攻击和内部反击不触发此限制。
- 不采用移动一次、攻击一次及攻击后自动结束行动的旧建议；行动次数由可用点数约束。

### 武将神力
- 神力属于武将本人；本人及所辖每支部队的事件分别计算，收益归属该武将，不按士兵人数计数。
- 首次初始化为0点，初始持有上限100点，可提升至最高400点。
- 神力跨内部交战、整场战斗、探索与下一场战斗持续保留，不自动清零或补满。
- 暂定收益：主动攻击＋1，主动攻击暴击额外＋1；反击＋0.5，反击暴击额外＋0.5；闪避＋1，内部防御反应＋1。不同事件可叠加，保留半点精度。
- 攻击被闪避仍获得攻击收益：主动攻击＋1或反击＋0.5；成功闪避方另获得＋1。
- 内部防御反应由武将或部队能力、概率触发，是受击反应；其具体效果后续制定。外部防御指令及其防御力buff本身不触发该神力奖励。
- 神眷基础消耗100点神力，部分技能升级后消耗可超过100点；须满足具体技能配置的神力消耗，并支付3点战斗行动力。
- 收益、上限、消耗与加成等平衡数值集中配置，避免分散硬编码；当前收益为暂定参数，后续通过战斗记录调整。

已确认的初始化与恢复：每场外部战斗开始时，移动行动力1点、战斗行动力2点；后续能力可按配置改变开战初值。第一回合使用开战初值，不额外恢复。从第二回合起，在整个战场每轮开始时统一恢复：移动固定＋1，战斗默认＋2（可按已确认规则提高），不超过当前持有上限。两类行动力只在本场战斗内通过待命继承，不跨战斗保留；神力跨战斗保留。

尚待明确：具体技能效果及P2实现范围。未定事项不由代码默认值代替确认。


### R3外部攻击距离（已确认）
- 外部攻击范围根据军团内部当前可作战成员（包括武将、部队）的最大攻击距离初步筛选，不固定为四向相邻。
- 横向或纵向相邻的外部距离增量为0；斜向相邻增量100；横向或纵向中间隔一个格子增量200。
- 内部每次攻击的实际距离＝原内部阵形距离＋本次外部距离增量。各成员仍分别判断自身射程及其他合法条件。只有至少一名当前可作战成员能按叠加后的距离、最小／最大射程及阵形阻挡规则攻击到一名合法敌方目标，才允许发起普通交战；最大射程仅用于初步筛选。
- 例如双方同列前排原距离100，外部斜向相邻增加100，实际距离200。
- 通用公式已确认：设横纵格位差的绝对值为dx、dy（双方处于不同格），外部距离增量＝200×(max(dx,dy)－1)＋100×min(dx,dy)。横纵互换结果相同；按双方位置计算，不使用移动绕行路径长度。
- 示例：位移(2,1)增量300，(2,2)增量400，(3,1)增量500；双方同列前排实际距离分别为400、500、600。


### R4整场胜负（已确认）
- 敌方所有外部军团均无可作战成员、我方仍有可作战成员时，我方胜利；反之失败。双方均无可作战成员时平局。
- 士兵耗尽但仍有可作战武将的军团不算被击败。一次内部交战结束而双方仍有可作战军团时，返回外部战场继续。
- 一次攻击及其反击完整结算后检查胜负，不在结算中途提前结束。
- P2不加入占领据点、坚持指定回合等特殊胜利条件。


### R5失去作战能力的军团占位（已确认）
- 军团全员失去作战能力后，移除外部格子占位，其他军团可以进入或经过该格。
- 该军团不再参与行动，也不能成为普通攻击目标。
- 保留军团编组、成员状态、战损及日志，不删除数据；内部零兵力或失能成员的阵形记录仍保留。
- 仍有可作战武将或部队的军团继续占位并参与战斗。
- 俘虏、救援及战场复苏机制尚未确定，不纳入本条。


### R6移动距离与地形（已确认）
- 移动行动力决定移动次数，移动范围决定单次距离；每次确认执行移动消耗1点移动行动力，不按经过格数扣行动力。
- 仅上下左右四向移动，不走斜角；军团单次移动范围取内部当前可作战成员（武将及部队）移动范围的最低值；失能武将及零兵力等不可作战部队不参与计算，独行武将使用自身移动范围。
- 按实际可达路径计算距离，绕行计入步数；可通行地形每格消耗1点移动距离，不可通行格不能进入。
- 友军占位格可以穿过，但不能作为移动终点；敌军占位格不能进入，也不能穿过。
- 预览和取消移动不扣行动力；确认执行时消耗。少于最大移动距离的移动同样消耗1点移动行动力。


### R7测试操控与退出（已确认）
- P2双方均由玩家手动操作，不加入敌方AI。
- 内部有限交战正常完成后返回外部战场，不提供正式撤退或直接跳出交战操作。
- P1测试中止只保留在独立测试入口，不作为正式战场撤退功能。
- 外部战场提供明确的重开测试按钮，重新加载整场初始数据（包括兵力、行动力、神力）。测试重置不属于正常战后流程；正常流程仍保留持续战损与神力。


## P2技能实施范围确认

- 已确认：P2暂不加入可实际使用的神眷技能。已确认的神力及神眷消耗规则仍保留，供后续接入；不提供扣除资源但无实际效果的神眷操作。
- 已确认：军团战技、战法、策略、道具在P2同样暂不加入实际效果；与神眷一起留待后续逐项定义和接入，不提供扣除资源但无实际效果的操作。
- P2基础战斗操作范围为移动、普通攻击、待命、防御。上述能力的已确认消耗与移动限制规则仍保留，供后续接入。
- 神力的P2交付范围已确认，见下节。


### 神力P2交付范围（已确认）
- 实现武将个人神力数据：首次初始化0点，默认上限100点；支持已确认的上限配置。
- 接入当前已支持的攻击、反击、暴击等事件，按已确认收益计算，记录数值来源及所辖部队的武将归属。
- 闪避、内部防御反应尚未实现时不制造相应事件，待机制加入后再接收益。
- 神力在多次内部交战和正常战后流程中保留；不加入磁盘存档，不扩大为P4探索场景开发。
- P2不提供神眷释放操作，神力只积累、不消耗。重开测试仍重新加载初始数据。

### 补充验收
- B11：军团移动范围取可作战成员最低值；友军可穿过不可停留，敌军不能进入或穿过。
- B12：外部距离增量在直向、斜向及远斜向示例中正确；内部最小/最大射程及阻挡校验正确，不允许全员无合法目标时发起交战。
- B13：防御只扣1点战斗行动力，结束当前军团行动，保留余点并增加50%防御力；在战场下一轮开始统一解除。
- B14：神力按个人及所辖部队正确归属；攻击＋1、暴击额外＋1，反击＋0.5、反击暴击额外＋0.5，支持半点；不超过上限，跨交战及正常战后保留，重开归初值。
- B15：平均速度只计可作战成员，内部＋200不参与；同值按固定ID，队列整轮固定，失能跳过，下一轮重算。
- B16：提高行动力上限/恢复量的测试配置可验证重复行动与待命积累，不需要实现特殊技能；神眷等暂缓能力不提供无效果扣点操作。
