# P1 内部交战测试台（第一版）

2026-11-06。实现基于用户确认的首版规则：所有可作战成员阻挡，失能/零兵力不阻挡；只允许无目标待机；开局固定排序；同速固定种子；双方手动指定目标。临时伤害每次扣10兵/伤势+1，3点伤势失能。临时数值不代表最终战斗公式。

## 操作验收

1. F5运行工程，点击左上方“P1：内部交战测试台”。原P0入口保留。
2. 查看双方各自三排四列阵形，当前每方1将2部队，空位保留。双方列号按同列对位，不因显示左右改变距离。
3. 查看当前行动者，点击其中一个合法目标按钮。一次点击完整执行攻击与可能的反击，再推进到下一行动者；双方均手动选敌。
4. 检查日志中的距离、行动顺序、待机、反击及剩余兵力/伤势，继续直到本次交战结束。
5. 返回外部战场，再次进入：行动重新恢复，战损保留。所有成员失能后再次进入会直接结束；重启程序恢复测试数据。
6. 面板打开时外部战场输入应停用。交战尚未结束时返回属于测试中止，不是正式撤退规则。

## 结构与限制

battle/Encounter.gd是独立于场景的结算对象，battle/TestBench.gd负责阵形、选择目标和日志。成员数据沿用P0持有的同一对象，测试台不会在进入时覆盖战损。

首版未提供编组编辑、数值编辑、随机种子编辑及自动选敌。测试属性通过TestBench首次进入时补齐；排序速度在本次交战固定。已加入交战入口编制合法性校验；尚未加入正式指挥惩罚、技能、完整伤兵阵亡划分、武将接任或存档。

P1首版范围已完成验收及收尾，可进入P2规则对齐；不代表正式战斗全功能已经完成。P0独立Windows exe仍待安装匹配导出模板后验证。
